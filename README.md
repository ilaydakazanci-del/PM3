# PM3-Public (HelpingHands Landing Page)

Dieses Repo enthält eine responsive, deutschsprachige Landing-Page für HelpingHands — Vermittlungsservice für handwerkliche Kleinaufträge.

Dateien:
- index.html
- styles.css
- script.js
- assets/ (optional: logo, bilder)

Schnellstart:
1. Dateien ins Repo laden
2. GitHub Pages aktivieren (Settings → Pages → Branch main / root)
3. BRAND-Block in index.html anpassen (Farben, logoUrl, companyName)
4. data-src der .video-iframe setzen (YouTube/Vimeo-Embed)
5. E-Mail-Adressen & Calendly & Datenschutz-Links anpassen
